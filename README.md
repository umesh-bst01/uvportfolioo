# Umesh Verma — Monochrome Editorial Portfolio

A second portfolio for Umesh Verma (AI & full-stack engineer) built on the
**ECHO** monochrome editorial design by [Jishnu Mondal](https://github.com/Jishnu09-siuu/ECHO-WEBSITE) (MIT).

- Orbital preloader, metallic typography, scroll-expand About card with a
  cycling showreel, horizontal experience timeline, WebGL liquid project
  carousel, 3D skills drum, achievements accordion, ambient music toggle.
- Stack: HTML + Tailwind v3 (CDN) + vanilla ES modules + OGL. No build step.

## Run locally

```
python3 -m http.server 8080
```

then open http://localhost:8080 (a server is required — the modules and
videos don't load over file://).

## Deploy

Any static host. On GitHub Pages: Settings → Pages → Deploy from branch →
main → / (root).
